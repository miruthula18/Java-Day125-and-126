
## Problems Solved

### 1. Ninja Clan Difference
**Description:** Find the absolute difference between the number of ninjas in two clans.

**Sample Input:**
100 200

**Sample Output:**
100

### 2. Perfect Square Product
**Description:** Find the product of two numbers and check whether it is a perfect square.

**Sample Input:**
5 5

**Sample Output:**
yes
